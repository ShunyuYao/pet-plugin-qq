# QQ 群反馈助手：首版试点使用说明

本地源码候选 `0.2.0-dev.1`，未上架、未发布安装包，不是已经完成真实 QQ 验收的正式版本。

## 需要准备

1. 本轮配套候选宿主：具有 `profile.getScope`、`conversation` 和支持 `context:'isolated'` 的 `ai.start`。仅凭宿主版本号不能判断是否支持；旧宿主不支持时不能回落成读取私人记忆的后台调用。
2. 一台专用电脑和同一个测试桌宠，保持 APP 开启；通过宿主正常设置模型服务。无需 DSH，也不要求 B 站插件。模型仍可能使用远程服务并产生费用。
3. 已登录的 NapCat OneBot v11 正向 WebSocket：本机根地址、令牌、机器人 QQ 与允许采集的群。建议消息格式选择数组。请自行用指定测试账号登录并入测试群，不将账号凭据或真实聊天原话放进 GitHub。

## 启动与安装

开发者先在配套宿主 `demo` 安装依赖、完成 `npm run react:build`。在本插件目录执行 `npm ci`，再运行：

```sh
PET_PLUGIN_HOST_DIR=/absolute/candidate-host/demo npm run pilot
```

`pilot` 启动可见的独立测试实例，使用名为 `turitopia-qq-feedback-pilot` 的专用数据目录，不借用日常 APP 的 profile。它不会自动登录、授权、复制账号或安装插件。也可以使用已有的兼容测试宿主。

在宿主正常完成登录和模型设置，然后进入「插件中心 → 开发者模式 → 手动安装 → 从文件夹安装」，选择含 `manifest.json` 的本插件目录并确认权限。若想使用干净的分发目录，可先运行 `npm run package:local`，选择打印出的文件夹；目录不含测试记录、模型密钥、QQ 登录态或宿主安装包。

## 连接指定群

打开「QQ 宠物连接」面板，默认是「群反馈助手」。填写 NapCat 本机地址、令牌、机器人 QQ、指定群号（逗号分隔）、原文保留天数与容量。

- 仅采集：不勾选模型整理，仍可查看收到的原文；不产生模型回复。
- 整理反馈：勾选「使用宿主模型整理反馈」并明确每日调用次数上限。
- 群内聊天：另外勾选「响应真实 @」。只回复触发原群，普通消息、@ 他人／全体和机器人自身消息不产生公开聊天回复。
- 先在试点群说明采集目的、访问对象、模型服务和保留期限，再勾选确认并连接。程序不会代你发布告知。

连接后可查看记录数、整理积压、模型错误和最近 @ 回复状态。普通消息分批整理，@ 聊天优先进入模型队列；一次只调用一个模型任务，调用间隔至少约 6.5 秒、每批最多 12 条、群回复最多 1000 字。每日次数是保守预留次数，不等于实际收费金额；真实 usage／账单以模型服务为准。

## 查看反馈与追问

面板可按群、类型、处理状态筛选。点一条反馈，查看原话、已知平台／版本／复现信息；未提供的信息显示待补充。模型新建条目均为「待确认」。可人工修改、确认、忽略、标记处理中／已解决，或依据同一份来源拆分为新反馈；相似条目只建议关联，不自动合并。

在桌宠原来的主聊天中问「今天群里有哪些 bug」，模型可调用只读 `qq_feedback_query`；追问某条的原话时查询其反馈 ID。只有主人桌面主聊天可调用，不允许群后台任务借用。桌面分析不会自动发送到 QQ。

如果此前把主聊天绑定到外部 DSH，会话由 DSH 管理，不会调用宿主的查询工具。使用本群模式前先在「已有 QQ 宠物 · DSH」页解除该绑定；这保留 DSH 原历史和桌宠本地数据。

## 暂停、恢复与故障

- 「暂停采集与模型任务」会关闭连接并停止正在等待的模型任务；已送到 QQ 的消息无法撤回。暂停偏好会持久化。
- 「恢复 / 重连」使用原配置。网络登录失效需先在 NapCat 正常恢复 QQ 登录，再回来重连。修改模型开关与预算前先暂停。
- 地址或令牌改变时，先暂停，再用「更新接入地址与令牌」保存，不必删除群资料；新令牌留空表示保持不变，只有明确勾选清空才删除令牌。
- 「重试本群整理失败项」只重试反馈识别，不重新发送聊天回复。发送结果未知时应到 QQ 核对，不自动重发。
- APP 退出／休眠／断网会停止服务，离线消息不保证补齐。进程中断后的未观测区间标为未知。
- 原文撤回／过期后，相关反馈标为来源已变化并移除派生内容；不能继续引用旧原文。已对外发送的群消息无法自动收回。
- 写入失败、容量满或积压过多会停采并报错，不会显示“已记录”。本地存储为 8 MiB 上限的加密试点快照，长期高流量容量和 Windows/Linux 尚需验收。

## 备份和清理

暂停并退出独立实例后备份专用 profile；其中可能包含私人数据和加密资料，不上传公共仓库。加密资料依赖本机安全存储，复制文件不代表能在其他设备解密；本期不提供跨设备同步。

清理必须先暂停，在面板明确输入「删除当前测试桌宠的群采集数据」再确认。会删除该作用域的群消息、反馈、任务及群连接凭据，不删除原 DSH 会话或其他桌宠数据；没有备份不可恢复。

## 当前验证边界

已有单元／协议与隐藏完整应用验证，QQ、短信和模型使用本地合成服务。因此能验证流程、隔离、路由、持久化与去重，但**不证明真实 QQ 登录可用或真实模型的反馈识别准确率**。正式试点需操作者在指定真实测试群验收，并记录漏报、误报、费用和长时间运行情况。
